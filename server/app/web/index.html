接口

  • GET /api/v1/dashboard 设备卡片数据
  • GET /api/v1/devices/{id} 单台详情
  • GET /api/v1/rankings 跨设备应用排行
  • POST /api/v1/devices/{id}/role 改角色
  • POST /api/v1/bot/command 命令测试（不经过 QQ）
  • GET /api/v1/devices/{id}/windows 当前打开的窗口
  • GET /api/v1/storage / POST /api/v1/storage/cleanup 存储统计与清理
  • GET/POST /api/v1/icons 应用图标

全部需要请求头 X-Ingest-Token。

配置

直接改服务端 config.yaml，注释与排版保持不变；保存后立刻热更新生效，机器人通道会自动重连，只有端口与数据库路径需要重启
